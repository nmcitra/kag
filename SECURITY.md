# Security

## Reporting

Report a vulnerability privately through GitHub's security advisory form for this repository (Security → Report a vulnerability). Do not open a public issue for it. You will get an acknowledgement within seven days and a fix or a reasoned response within thirty.

## Scope

This repository's code and its published releases. Deployment guides and product integrations live elsewhere and are out of scope here.

## Practice

Secret scanning and push protection are on. Dependencies are pinned and Dependabot proposes updates. Tags are signed; commits carry a DCO sign-off. Nothing runnable is claimed secure until a tagged release runs the adopted KTP conformance suite and an independent party confirms it.
